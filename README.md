## 🧑‍💻 About Me

🏫 &nbsp; I graduated from **[Carnegie Mellon University](https://www.cmu.edu/)** with a Masters degree

📊 &nbsp; I build data systems, production-grade ML models, and AI-powered applications that go from raw data to a working product

My path into data science started in ⚙️ **Mechanical Engineering** - cleaning 220K+ sensor records from 52 industrial channels, running EDA across pump failure events, and building an XGBoost model that isolated the 9 highest-signal features. That project showed me how much a well-scoped model can change how engineers make decisions.

Since then, I've worked across domains. At **Pittsburgh Penguins**, I built an ML pipeline on youth hockey profiles to build a talent identification model. At **MSA Safety**, I built an ML-based indirect refrigerant leak detection system to be integrated with a direct leak detection system for predicting early leaks.

On the AI side, I've built RAG pipelines with ChromaDB, deployed LLM-powered apps using the Claude API, trained CNNs on EMNIST and audio embeddings, and served multimodal inference stacks with FastAPI and Hugging Face.

Whether it's 🌍 climate forecasting for Rwandan districts, 🔍 evaluating UN humanitarian fund efficiency, or 🔋 EV battery warranty benchmarking across 34 EV manufacturers - I like building things that give stakeholders a real answer.
